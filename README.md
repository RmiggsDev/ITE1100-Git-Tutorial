# ITE1100 Git Tutorial #4

This repository was created as part of the ITE 1100 Tutorial. 
The purpose of the exercise was to gain practical experience in using Git and GitHub, 
and to understand how developers can work together on the same project and keep track of its changes.
These are the steps I took to complete this tutorial:
1. Installed Git and created a GitHub account
2. Created a local Git repository and connect it to GitHub
3. Added a classmate as a collaborator
4. Created a separate branch for our project
5. Added a python file called sample.py
6. Committed and pushed our changes to GitHub
7. Created a pull request for review
8. Received approval from our collaborator
9. Merged the approved changes into the main branch.

I used the Mac Terminal to run the Git commands and manage our local repository branch.
